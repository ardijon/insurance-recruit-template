# COMMANDS-fa.md — چیت‌شیت دستورات (کی، کجا، چرا)

نکته مهم: بعد از راه‌اندازی اولیه، تقریباً هیچ‌وقت لازم نیست خودت این دستورا رو
تایپ کنی — چون `AGENTS.md` به *ایجنت* می‌گه کِی گراف رو آپدیت کنه، و هوک گیت
(بخش بعدی) بقیه‌ش رو خودکار می‌کنه. این جدول فقط برای وقتیه که بخوای دستی
دخالت کنی یا چیزی رو دیباگ کنی.

## کجا تایپ می‌شه؟

- دستورهایی که با `graphify` یا `uv` شروع می‌شن → **ترمینال** (همون ترمینال
  VSCode یا هرجا که OpenCode رو ازش اجرا می‌کنی)
- دستورهایی که با `/graphify` شروع می‌شن → **داخل چت OpenCode** (یا Claude Code)

## یک‌بار برای همیشه (نصب)

| کِی | دستور | کجا |
|---|---|---|
| اولین بار روی این ماشین | `uv tool install graphifyy` | ترمینال |
| اولین بار روی این پروژه | `graphify install --platform opencode` | ترمینال |
| اولین بار روی این پروژه | `graphify opencode install` | ترمینال |
| بعداً اگه Claude Code هم اضافه شد | `graphify install` و `graphify claude install` | ترمینال |

## روزمره (و چطور خودکارش کنیم)

| کِی | دستور | کجا | خودکار می‌شه؟ |
|---|---|---|---|
| اولین بار که کد وجود داره | `/graphify .` | چت OpenCode | نه، دستی |
| بعد از هر تغییر ساختاری (فایل/ماژول جدید) | `/graphify . --update` | چت OpenCode | **بله** — `AGENTS.md` به ایجنت می‌گه خودش این کارو بعد از هر فاز بزنه |
| بعد از هر کامیت گیت | — | — | **بله**، اگه `graphify hook install` رو یه‌بار بزنی (پایین توضیح دادم) |

## دستوراتی که فقط برای پرسیدن سوالن (هروقت خواستی)

| هدف | دستور |
|---|---|
| یه سوال درباره کدبیس | `graphify query "..."` |
| مسیر ارتباط بین دو چیز | `graphify path "A" "B"` |
| توضیح یک تابع/کلاس/ماژول | `graphify explain "Name"` |

اینا رو معمولاً لازم نیست خودت بزنی — ایجنت به‌جای گرفتن (grep) خودش اینا رو
صدا می‌زنه. فقط وقتی مفیدن که خودت می‌خوای سریع یه چیزی رو بفهمی بدون اینکه از
ایجنت بخوای.

## خودکارسازی کامل آپدیت گراف

```bash
graphify hook install
```

این یه‌بار بزن. از اون به بعد:
- بعد از هر `git commit` گراف خودش با AST محلی (بدون هزینه API) بازسازی می‌شه.
- یه merge driver گیت هم نصب می‌شه که اگه دو نفر (یا دو سشن) هم‌زمان کامیت کنن،
  `graph.json` بدون conflict merge می‌شه.

اگه می‌خوای حتی بدون کامیت کردن هم گراف زنده بمونه (مثلاً وسط یه سشن طولانی):

```bash
graphify watch ./src
```

این توی یه ترمینال جدا اجرا می‌مونه و هر تغییر فایل رو فوری روی گراف اعمال می‌کنه.

## خلاصه یک‌خطی

بعد از نصب اولیه، تنها کاری که واقعاً خودت باید بکنی اینه: **پرامپت فاز رو توی
چت OpenCode بفرستی** (نگاه کن به `PHASE-PROMPTS-fa.md`). بقیه‌ش (آپدیت گراف،
کوئری گرفتن) رو `AGENTS.md` + `graphify hook install` برات خودکار می‌کنن.
