# GRAPHIFY-CHECKLIST-fa.md — چک‌لیست دستورات، فقط برای پروژه‌های بزرگ

⚠️ این فایل رو فقط دنبال کن اگه `prompts/setup-interview.md` گام ۰ (تست اندازه
پروژه) نتیجه‌ش **بزرگ** بود و `Graphify: yes` رو توی `AGENTS.md` بخش ۱ ثبت
کردی. اگه پروژه کوچیکه، این فایل رو کلاً نادیده بگیر.

از بالا به پایین، دقیقاً به همین ترتیب:

## ۱. نصب (یک‌بار روی این ماشین)

```bash
uv tool install graphifyy
```

اگه دستور `graphify` بعدش پیدا نشد:

```bash
uv tool update-shell
```
و یه ترمینال جدید باز کن.

## ۲. ثبت پلتفرم (یک‌بار روی این پروژه)

```bash
graphify install --platform opencode
```

## ۳. فعال‌سازی همیشگی (یک‌بار روی این پروژه)

```bash
graphify opencode install
```

این خودش یه بخش به `AGENTS.md` اضافه می‌کنه — دستی ویرایشش نکن.

## ۴. خودکارسازی آپدیت (یک‌بار روی این پروژه، خیلی توصیه می‌شه)

```bash
graphify hook install
```

از این به بعد، بعد از هر `git commit`، گراف خودش بازسازی می‌شه — دیگه لازم
نیست نگرانش باشی.

## ۵. ساخت اولین گراف (بعد از این که کد اولیه از فاز Scaffold ساخته شد)

توی چت OpenCode بزن:

```
/graphify .
```

## ۶. کار روزمره — هیچی دستی نیست

از اینجا به بعد، آپدیت گراف خودکاره (مرحله ۴) و کوئری‌گیری رو خودِ ایجنت
انجام می‌ده (طبق `AGENTS.md` بخش ۵). فقط اگه خواستی خودت دستی یه چیزی رو
بپرسی:

```bash
graphify query "..."
graphify explain "..."
```

## ۷. (اختیاری) اگه بعداً Claude Code هم اضافه کردی

```bash
graphify install
graphify claude install
```
