# PHASE-PROMPTS-fa.md — پرامپت‌های آماده برای هر فاز

نکته مهم قبل از شروع: لازم نیست هیچ فایلی رو دستی توی OpenCode "باز" کنی.
وقتی OpenCode رو داخل پوشه پروژه اجرا می‌کنی، خودش `AGENTS.md` رو در ابتدای
سشن می‌خونه. کاری که باید انجام بدی فقط اینه: توی چت OpenCode، پرامپت هر فاز
رو (پایین‌تر) کپی-پیست کنی و منتظر تایید/سوال بعدی بمونی.

ترتیب فازها:

```
۰. مصاحبه و تکمیل قوانین  →  ۱. Scaffold  →  ۲. API Layer  →
۳. Hooks  →  ۴. Components  →  ۵. Polish
```

---

## فاز ۰ — مصاحبه (تکمیل edge.md و design.md)

از این استفاده کن اگه `edge.md` یا `design.md` هنوز جای خالی (placeholder) دارن.
این فاز رو *قبل* از هر فاز دیگه انجام بده. اولین کاری که این پرامپت انجام
می‌ده، تست اندازه پروژه‌ست (۵ معیار عینی) — بعدش تصمیم می‌گیره Graphify لازمه
یا نه، و فقط بعد از اون میره سراغ سوالای edge.md/design.md.

```
طبق prompts/setup-interview.md عمل کن. edge.md و design.md رو باز کن، ببین
کدوم بخش‌ها هنوز خالی‌ان، و با پرسیدن سوال‌های کوتاه (یکی‌یکی، نه همه با هم)
اونا رو کامل کن. اگه پروژه از قبل کد داره (مثلاً تنظیمات Tailwind یا
package.json)، اول خودت از روی کد حدس بزن و برای تایید بهم نشون بده، به‌جای
اینکه از صفر بپرسی. بعد از تکمیل هر دو فایل، خلاصه‌ای از چیزی که نوشتی نشونم
بده و منتظر تایید من بمون.
```

---

## فاز ۱ — Scaffold (ساخت زیرساخت اولیه)

فقط بعد از تایید فاز ۰:

```
edge.md و design.md تکمیل و تایید شدن. طبق AGENTS.md بخش ۳ (چرخه توسعه) و
prompts/scaffold.md، فاز Scaffold رو شروع کن. فقط ساختار پوشه/ماژول‌هایی که
تو edge.md قفل شده رو بساز، بدون UI یا edge-case handling. آخرش بهم بگو کِی
باید /graphify . رو بزنم.
```

بعد از تایید خروجی این فاز، توی چت بزن:

```
/graphify .
```

طبق AGENTS.md، فاز API Layer رو شروع کن — لایه ارتباطات/داده طبق edge.md بخش
۲ و ۳. قبل از نوشتن کد، اگه گراف موجوده ازش برای فهمیدن ساختار فعلی استفاده
کن (graphify query) به‌جای خوندن کل فایل‌ها.
```

```

## فاز ۴ — Components (رابط کاربری)

```
فاز Components رو شروع کن. قبل از نوشتن هر کامپوننت، design.md رو چک کن —
فقط از توکن‌ها و الگوهای همون فایل استفاده کن. اگه چیزی نیاز داری که توش
نیست، طبق design.md بخش ۰ (Change-Control) اول پیشنهاد بده و منتظر تایید من
بمون، خودسرانه چیز جدید نساز.
```

## فاز ۵ — Polish (نهایی‌سازی)

```
طبق prompts/polish.md فاز Polish رو اجرا کن: چک‌های tsc/eslint، چک‌لیست بصری
design.md بخش ۶، و اگه ساختار تغییر کرده /graphify . --update رو بزن. آخرش
یه خلاصه از چیزی که تغییر کرد و چیزی که نیاز به تایید من داره بهم بده.
```

## نکته برای پروژه‌های کوچیک

پرامپت فاز ۰ (بالا) خودش این تصمیم رو می‌گیره — لازم نیست خودت جدا حدس بزنی.
اگه تست ۵ معیاری `prompts/setup-interview.md` نتیجه‌ش کوچیک بود، `AGENTS.md`
با `Graphify: no` تنظیم می‌شه و از اون به بعد هیچ‌جای این چرخه سراغ گراف
نمی‌ره — همون `edge.md`/`design.md`/`roadmap.md` ساده کافیه.
