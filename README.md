# سایت اختصاصی مدیر فروش بیمه عمر

قالب Next.js برای جذب نماینده — نسخه Scaffold (فاز ۱ از `roadmap.md`).

## راه‌اندازی

```bash
npm install
cp .env.example .env.local   # بعداً برای فاز ۳ (تلگرام) پر می‌شود
npm run dev
```

پایگاه‌داده SQLite در اولین اجرا به‌صورت خودکار در `data/app.db` ساخته
می‌شود (طبق `lib/schema.sql`). هیچ سرویس دیتابیس جداگانه‌ای لازم نیست.

## وضعیت فعلی (طبق roadmap.md)

- ✅ **Phase 1** — ساختار پایه: صفحات، کامپوننت‌ها، اسکیمای دیتابیس، توکن‌های
  رنگ روشن/تاریک، فونت وزیرمتن، RTL. محتوا هنوز placeholder است.
- ⬜ Phase 2 — فرم درخواست نمایندگی (اعتبارسنجی کامل + ذخیره واقعی)
- ⬜ Phase 3 — اتصال تلگرام + امتیازدهی خودکار
- ⬜ Phase 4 — لینک ارجاع نماینده‌ها
- ⬜ Phase 5 — ارزیابی اولیه تناسب فروش (اختیاری)

جزئیات کامل هر فاز در `roadmap.md` پروژه اصلی است (این ریپو فقط کد است،
فایل‌های `edge.md` / `design.md` / `roadmap.md` / `AGENTS.md` را از پروژه
اصلی خودت کنار این کد قرار بده).

## نکته درباره better-sqlite3

`better-sqlite3` یک ماژول native است و در `npm install` کامپایل می‌شود.
این کار به یک کامپایلر C++ (روی اکثر سیستم‌عامل‌ها از قبل نصب است) و
دسترسی اینترنت برای دانلود هدرهای Node.js نیاز دارد — این محیطی که این
قالب اولیه‌سازی شده بود، آن دسترسی را نداشت، برای همین فقط type definitions
(`@types/better-sqlite3`) نصب و تایپ‌چک شد، نه خودِ ماژول. روی سیستم خودت
با اینترنت عادی، `npm install` بدون مشکل کامپایلش می‌کند.
